If a channel will not play, it may be offline, geo-blocked, or blocked by the browser (CORS or http://). A proxy can fix the last two: open Settings (gear icon).

Proxy settings

A proxy lets your browser play streams that block cross-origin requests or use http:// on this https page. Your proxy address is saved only in this browser.

{url} is replaced by the encoded stream address. If you leave it out, the address is added to the end.

Set up a free proxy (Cloudflare Worker)
  1. Create a free account at dash.cloudflare.com, then open Workers & Pages and choose Create, then Worker.
  2. Replace the sample code with the contents of proxy/cloudflare-worker.js from this repository (set ALLOWED_ORIGINS to your site address) and click Deploy.
  3. Copy the worker address, for example https://iptv-proxy.yourname.workers.dev, and enter it above as https://iptv-proxy.yourname.workers.dev/?url={url}.
  4. Press Test, then Save.
